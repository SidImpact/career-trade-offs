# ⚖️ Career Trade-Offs

**Discover the true cost of your career path before you commit.**

Every career has a price—whether it's your time, mental health, physical toll, or financial runway. **Career Trade-Offs** is a modern Next.js web platform that helps students, professionals, and career-switchers visualize and compare the hidden struggles, peak salaries, and AI displacement risks of over 50+ professions, powered by a dynamic AI generation engine.

![Career Trade-Offs Demo](/public/images/explore.jpg)

## 🚀 Features
- **Trade-Off Profiles:** In-depth, structured breakdowns of 48+ built-in careers.
- **Dynamic AI Generation:** Can't find your niche? The integrated Gemini AI engine generates a complete, realistic trade-off profile for *any* career in seconds.
- **Side-by-Side Comparison:** Compare up to 3 careers simultaneously using interactive radar charts (financial reward vs. mental toll vs. physical toll).
- **Career Quiz:** A personalized onboarding quiz that matches users to optimal careers based on their struggle tolerance and priorities.
- **Lightning Fast:** Fully optimized with Next.js App Router, Turbopack, and Server-Side Generation (SSG) for instant page loads.
- **Spam-Protected Feedback:** Integrated Nodemailer feedback system with honeypots and rate-limiting.

## 🛠️ Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS + Lucide Icons
- **Data Viz:** Chart.js + react-chartjs-2
- **AI Engine:** Google Gemini API
- **Search:** Fuse.js (Fuzzy search)
- **Deployment:** Vercel / Netlify Ready
